# Enhancers Academy Coaching Website

Enhancers Academy Coaching Website is a modern, responsive, and user-friendly web application built using **Angular**. This project is designed for a coaching institute to showcase its courses, vision, student guidance, and academy information in a clean, professional, and engaging way.

The website helps create a strong online presence for the academy and makes important information easily accessible for students and parents.

---

## Features

- Responsive and modern user interface
- Hero section with academy introduction
- About Us section
- Vision and mission section
- Personal guidance section
- Course highlights section
- Contact information section
- Clean and structured layout
- Student-friendly design

---

## Tech Stack

- Angular
- TypeScript
- HTML
- SCSS
- Tailwind CSS

---

## Purpose of the Project

The main purpose of this project is to build a professional coaching institute website that presents academy details, courses, values, and guidance system in an attractive and organized format.

---

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Zentrok-Private-Limited/Enhancers-academy

```
## 2. Navigate to the project folder
```bash
cd Enhancers-academy

```
## 3. Install dependencies

```bash
npm install

```
## 4. Run the development server

```bash
ng serve

```
## 5. Open in browser

```bash

http://localhost:4200/

```
## Build

```bash

ng build
